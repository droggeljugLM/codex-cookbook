# Codex 协作 Cookbook

一个面向 Codex 协作场景的单文件网页手册。

这个网页把常见的 Codex 使用场景整理成可直接取用的“菜谱”，包括需求诊断、方案收敛、直接开发、Bug 修复、技术债挂账、失败复盘、验收闭环等。

## 特点

- 单文件 HTML，无需安装依赖
- 左侧场景索引，快速定位使用场景
- 每个菜谱包含可复制提示词
- 支持提示词折叠与展开
- 支持移动端侧边栏导航
- 包含最终检查清单，方便提交任务前自查

## 使用方法

直接打开 `index.html` 即可使用。

也可以部署到 GitHub Pages、Netlify、Vercel 等静态网页平台。
